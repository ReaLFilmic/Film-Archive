기록 가져오기 왓챠피디아 · 레터박스에서 내려받은 CSV 를 그대로 넣으면 됩니다

왓챠피디아 — github.com/erinyskim/watchapedia-export 의 방법으로 CSV 를 내려받습니다. 주소창에 javascript: 를 치고 그 뒤에 스크립트를 붙여넣는 방식입니다.
레터박스 — Settings → Import & Export → Export Your Data 의 ratings.csv.
어느 쪽이든 형식을 알아서 알아봅니다. 영화만 가져오고 TV 는 건너뜁니다.

먼저 아래 TMDB 연결에서 키를 넣어주세요. 제목을 TMDB 와 맞추는 데 씁니다.

포스터 · 예고편 · 스틸컷 불러오기 TMDB API 키를 넣으면 36편의 실제 이미지가 채워집니다

키 받는 방법 — themoviedb.org 회원가입 → 설정(Settings) → API → 키 요청. 무료이고 승인은 보통 바로 됩니다. 용도는 개인 학습 프로젝트로 적으면 됩니다.
그 화면에는 API Key (v3 auth) 32자와 API Read Access Token(eyJ… 로 시작하는 긴 문자열)이 함께 있습니다. 둘 중 아무거나 넣으면 알아서 맞는 방식으로 보냅니다.

메타크리틱 · 로튼토마토 점수는 TMDB 가 주지 않습니다. omdbapi.com 에서 무료 키(하루 1,000회)를 받아 넣으면, 케이스를 꺼낼 때 함께 표시됩니다. 비워둬도 나머지는 정상 동작합니다.

한 번 받아두면 열 때마다 자동으로 연결됩니다

키는 이 브라우저 화면에만 머물고 어디에도 전송되지 않습니다. TMDB 서버로만 요청이 갑니다.

실제 서비스에서는 이렇게 하지 않습니다. 브라우저에 키를 넣으면 누구나 볼 수 있습니다. Flask로 만들 때는 키를 서버 환경변수에 두고, 브라우저는 내 서버에만 요청해야 합니다. 여기서는 서버가 없는 프로토타입이라 편의상 이렇게 둔 것입니다.
